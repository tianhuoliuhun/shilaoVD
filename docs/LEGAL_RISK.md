## 二、已确认不存在的功能（降低风险的事实）

- 没有下载、保存、导出、分享视频的功能（已检索代码中的 `download`、`下载`、`分享`、`保存到`、`导出`）。
- 没有登录态：只使用游客身份的 `ttwid` Cookie，不读取、不注入任何用户账号。
- 没有广告、付费、会员功能。

## 三、建议的下一步（按优先级）

1. **咨询律师**：重点评估第 3、4 项。这两项决定是否可以公开分发，工程上无法替代判断。
2. **收窄分发**：如果律师认为风险较高，可以只保留自用版本，不在 Releases 公开发布。
3. **保持非商业性**：不加广告、付费、会员。商业化会显著放大风险。
4. **建立下架渠道**：在 README 中写明联系方式，收到权利方的删除请求时能及时处理。
